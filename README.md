# Поля Гумер — birthday edition ♡

Розовый сайт-поздравление с 11 фотографиями, конфетти, письмом, пожеланиями и необязательной синтезированной мелодией.

## Открыть
Скачайте `index.html` и откройте его в браузере. Интернет, сервер и установка не нужны: все фотографии, стили и скрипт внутри файла. На телефоне сохраните файл и откройте именно в браузере; встроенные предпросмотры мессенджеров могут не выполнять JavaScript.

## Изменить
Текст, CSS и JavaScript находятся в `index.html`. Зависимостей нет. Учитывается настройка уменьшенного движения.

Публичный репозиторий: https://github.com/arturbro6/polya-birthday
